# 数智游踪 · 答辩演示资料

> **数智游踪——智慧景区沉浸式 AI 导览助手**<br>
> 第十五届“中国软件杯”大学生软件设计大赛 A5 赛题“景区导览服务 AI 数字人”参赛项目

本仓库集中保存“数智游踪”项目的答辩 PPT、逐页视觉生成稿、赛题说明与配套图片素材。它用于呈现产品方案、核心技术、功能覆盖和应用价值，不包含完整项目源代码及部署环境。

## 项目简介

“数智游踪”面向无锡灵山胜境与拈花湾禅意小镇等智慧文旅场景，为游客和景区运营人员提供一体化 AI 导览服务。

- **游客侧**：通过文本或语音与 AI 数字人交流，获取景区知识问答、景点讲解、个性化路线推荐和服务反馈入口。
- **管理侧**：维护景区知识文档和数字人配置，查看问答质量、游客感受度与运营数据，并形成持续优化闭环。
- **智能能力**：以本地景区知识库约束回答边界，结合 RAG 检索、语音识别与合成、数字人驱动和路线推荐，兼顾交互体验、事实可信度与服务连续性。

项目希望回应传统景区导览中的六类问题：旺季导游资源紧张、语言服务不连续、讲解信息单向固定、路线缺少个性化、设备缺乏情感互动，以及运营数据难以支撑管理决策。

## 赛题要求与方案对应

| 赛题关注点 | 数智游踪方案 |
| --- | --- |
| 多模态交互 | 文本、语音、TTS、口型、表情与数字人动作协同 |
| 智能问答与讲解 | 本地知识库、混合检索、RAG 有据生成、引用与无据拒答 |
| 个性化推荐 | 综合游客兴趣、游览时长、体力偏好与景点关系生成路线 |
| 知识库管理 | 支持知识文档维护、检索测试和问答质量修正 |
| 数字人形象管理 | 采用统一表达接口，支持讯飞云端流式数字人与 Live2D 本地模型配置 |
| 游客洞察与数据概览 | 汇总交互、反馈、满意度、热门问题与服务趋势 |
| 稳定性与降级 | 云端形象异常时可切换本地数字人，继续异常时保留文本、引用与路线服务 |

答辩材料记录的当前工程规模为：**5 种界面语言、22 个景点实体、44 个知识分块、45 项业务 API**。这些数字用于说明当前演示版本的功能与数据边界，不替代正式测试报告。

## 视觉设计

整套演示以“**东方禅意文旅 + 可信 AI 科技**”为视觉定位，将灵山、莲花、山水、金色佛光与江南园林等文化意象，与数字人、数据流、知识节点和全息界面结合。

- 主色：黛青 `#173B45`
- 科技色：湖青 `#35B7C6`
- 文化色：鎏金 `#D6A84B`
- 活力色：玉绿 `#55A88B`
- 强调色：朱砂 `#D9654F`
- 背景色：暖白 `#F6F3EC`

原创 AI 景区数字人 IP“**灵悦**”承担产品导游形象：采用现代新中式导览服、莲花与游踪路线纹样，并保持亲切、专业、可信的角色气质。
